# 📊 Job Market Intelligence Platform

An end-to-end Job Market Intelligence platform that collects job-market data, cleans and enriches it, performs analysis, and provides machine-learning predictions through an interactive Streamlit dashboard.

## 🚀 Live Application

🔗 https://jobmarketintelligence-3appgkxr8avjmjpmrnx4as.streamlit.app

## 📌 Project Overview

The Job Market Intelligence Platform is designed to help users explore job-market trends, analyze salaries, inspect job postings, and generate ML-based predictions.

### Key capabilities

- 🌍 Global job-market exploration
- 📈 Job-market trend analysis
- 💰 Salary analysis
- 🤖 Machine-learning predictions
- 🔎 Interactive data exploration
- 📊 Model performance evaluation
- 🎯 Global filters for country, city, category, date range, and contract type
